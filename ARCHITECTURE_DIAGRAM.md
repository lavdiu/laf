## Data Flow Example: Creating a User

```
1. Application Code
   ↓
   $user = new User(name: 'John', email: 'john@example.com');
   $userRepo->save($user);

2. Repository Layer
   ↓
   UserRepository::save(User $user)
   ├── Checks if $user->id is null
   ├── Calls insert() or update()
   └── Returns saved User

3. Abstract Repository
   ↓
   AbstractRepository::insert(User $user)
   ├── Converts $user->toArray()
   ├── Builds INSERT query
   └── Executes via Connection

4. Connection Layer
   ↓
   Connection::execute(string $sql, array $bindings)
   ├── Prepares PDO statement
   ├── Executes with bindings
   ├── Tracks statistics
   └── Returns affected rows

5. Database
   ↓
   MySQL/PostgreSQL executes query
   └── Returns last insert ID

6. Return Path
   ↓
   Connection → Repository → Application
   └── User object with ID populated
```

┌─────────────────────────────────────────────────────────────────┐
│ Post Model                                                      │
│ ├── user(): ?User             (Many-to-One via user_id)       │

- ✅ **PHP 8.4 Features**: Property hooks, attributes, enums, readonly
