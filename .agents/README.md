# Antigravity Workspace Customizations (`.agents/`)

This directory houses project-specific Antigravity customizations:
- `rules/`: Modular, directory-scoped markdown guidelines (`.agents/rules/*.md`).
- `skills/`: Project-specific skills and workflows (`.agents/skills/<name>/SKILL.md`).
- `plugins/`: Bundled skills, rules, and MCP configurations (`.agents/plugins/<name>/plugin.json`).
- `skills.json` / `plugins.json`: Manifest files for custom path registration.

Checked into version control to share agent procedures and guidelines across your development team.
